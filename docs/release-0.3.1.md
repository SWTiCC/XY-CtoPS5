# XY-CtoPS5 v0.3.1 更新说明

> 一句话：**手柄的「原生震动」（音频触觉）在这一版真正修好了**——从完全没反应，到游戏里
> 手感接近原生；同时修掉扳机卡键、灯条不跟游戏、一个会把程序整个带崩的致命错误，
> 以及几处「看着正常、其实一直没生效」的问题。键鼠玩法保持原样。

## 一、手柄震动（这一版的重点）

### 之前是什么样

- USB 插着、游戏里在开枪，手柄**一点震动都没有**；
- 偶尔有反应，也是**细碎的噪声**，不像震动；
- 有时又会在**不该震的时候震一下**，持续震动时还夹着「不断抽动」。

### 现在是什么样

- 游戏里的撞击、开枪、油门、刹车、路面摩擦都有对应震动，**手感接近原生**；
- 持续震动**不再抽动**，也不会在安静的时候突然震一下；
- 手柄页新增**「震动方式」三选一**：`音频触觉（USB）` / `经典马达` / `关闭`。

### 到底修了什么

1. **触觉数据被当成了压缩音频去解码**。主机下发的触觉数据是**原始 3kHz 立体声 PCM**，
   不需要解码；之前多解了一次，出来自然是噪声。现在直接按 PCM 写进手柄的四声道音频端点
   （声道 1/2 是扬声器，3/4 是触觉执行器）。
2. **手柄内部的音频通路默认是关着的**。接到 PC 上时，手柄的扬声器音量是 0、静音和省电位
   是打开的——数据到了设备上也不会响、不会震。现在连接手柄时补一帧把它打开
   （音量 100%、清静音、清省电位、关触觉低通）。
3. **「马达使能位」会把音频触觉静音**。原来每一帧输出报告都带着马达使能位，手柄会切到
   「兼容震动」模式，音频触觉随即失效。现在 USB 触觉生效时统一进入「触觉模式」，
   所有报告都不带马达使能位，也不再转发经典马达；关掉触觉或走蓝牙时自动恢复马达通道。
4. **重复帧和乱序旧帧被重播**。网络重传会把同一段触觉送两遍，晚到的旧帧还会插到新帧后面。
   现在只播「帧序号更新」的帧，重复和过期的直接丢弃。
5. **主机送包是突发的，缓冲必须留余量**。实测相邻包间隔中位 4.8ms、p99 38.7ms，
   没有缓冲时每秒都会「断一次」，听起来就是抽动。现在保留 **40ms 抖动缓冲**
   （攒够再播、断流后攒回再继续），断流时输出静音而不是保持一个固定力度。
6. **不做播放速率自适应**。试过按缓冲余量微调播放速度，结果在 47~60Hz 的低频震动上
   等于持续变调，手感反而更差，最终改回固定速率：宁可偶尔静音一下，也不让已经出来的震动变调。

### 已知限制（硬件/协议层面，不是没修）

- **必须 USB 连接手柄**。蓝牙下 Windows 不会暴露那个四声道音频端点，触觉无处可写——
  蓝牙只剩自适应扳机，这是硬件限制。
- **串流下的触觉带宽是 3kHz**，高频细节不如手柄直连主机时的 48kHz；
  另外远程游玩里主机不下发「扳机马达类」效果，所以「手柄前面的高频震动」这类反馈在串流下拿不到。

## 二、自适应扳机

- **左右不再互相覆盖**：两侧效果合成一份报告一起写；之前分两次写，后一次会把前一次顶掉，
  表现就是「效果时有时无、只有一边生效」。
- **扳机卡住（按过 L2 后松不开）已修**：主机侧的事件窗口很窄，一侧松手、另一侧还在抖动时，
  「松开」会被挤出窗口。现在加了扳机值过滤（端点吸附 + 中间步长 + 松手后短暂抬高另一侧阈值），
  浅踩油门这类小幅输入不会被吞掉。

## 三、灯条

手柄灯条跟随游戏内颜色变化；手柄断开重连后会重新写一次，不会一直停在手柄的默认颜色。

## 四、稳定性与输入

- **修掉一个会把程序整个带崩的致命错误**：键盘/鼠标底层监听的隐藏窗口原来挂着 Python 回调，
  在特定时机会让程序直接退出（不是普通的报错弹窗）。现在这条路径不再有 Python 回调，
  同时开启了崩溃记录（`faulthandler.log`），以后再遇到会留下现场。
- **鼠标拖动画面不动（键鼠玩法）已修**：底层鼠标数据偶尔完全不出数时，退回用光标位移计算，
  但之前的兜底逻辑被一个 bug 废掉了，永远算出 0。修好后右摇杆峰值从 0.01 回到 1.00。
- **键鼠 / 手柄两个玩法彻底隔断**：同一时刻只创建当前玩法那一侧的输入对象——键鼠玩法下
  不碰手柄（不读手柄、不占触觉音频端点、不写灯条/扳机），手柄玩法下不装键盘鼠标监听、
  不注册全局热键、不铺覆盖层。切换玩法时先把旧玩法整套拆掉，再建新的。
- 其他小修：手柄断开时马达归零、音频端点释放；多只手柄时不做触觉路由（分不清是哪只的端点）；
  没连手柄时不再尝试写触觉；第二次启动直接切回已有窗口（单实例）。

## 五、验证情况

- 单元测试 **210 个全绿**；
- **实机确认**：USB 下游戏内触觉正常、经典马达「试震动」正常、打开音频通路后扬声器有声、
  键鼠输入与陀螺仪不受影响；触觉抽动问题修复后，一局里断流次数不再增长、缓冲稳定。
- 蓝牙行为不变：只有自适应扳机，没有触觉（硬件限制）。

## 六、使用提示

1. 用手柄玩法：先在「手柄」页确认识别到 DualSense，**USB 线插到 PC**（不是插到 PS5）；
2. 手柄页的**震动方式**三选一：`音频触觉（USB）`（最接近原生，插线自动生效）/
   `经典马达`（USB 与蓝牙都能用）/ `关闭`——两者互斥，所以是一个选择器而不是两个开关；
3. 触觉异常时先看日志这三行：`触觉输出：…` → `已打开手柄音频通路…` →
   `已打开 DualSense 触觉端点…48000 Hz，4 声道`；
4. 触觉持续抽动、或安静时乱震，日志里会出现一条 `触觉流：… 欠载 …`，把那条发出来即可定位
   （正常玩一局不应该频繁出现）。
