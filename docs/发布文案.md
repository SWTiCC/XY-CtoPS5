## 简介（可直接复制）

```
PS5 上玩单机，用键盘鼠标瞄准比手柄舒服太多。
XY-CtoPS5 是一个开源免费的小程序：画面走采集卡 HDMI 环出，输入走 PS5 的 Remote Play 通道，把键鼠伪装成 PS5 手柄。游戏本身不用改，也不会被当成外挂。

这次 v0.3.0 加了「手柄」玩法：
把手柄用 USB 或蓝牙接到电脑，直接用真手柄玩 PS5，画面同样走采集卡。
· 陀螺仪 → 右摇杆：按住激活键就能靠手部姿态微调视角，松手立刻停。激活键可以是手柄上任意一个键，灵敏度 / 死区 / 平滑 / 反 X 反 Y 都能调，带一个游戏式的校准引导
· 抓包诊断：能查看主机下发的负载类型，用来确认震动和扳机数据走哪条通道

===== 手柄功能现在的状态（重要）=====
✅ 自适应扳机：已经适配完成，实机验证过。主机下发的开枪、发动、开车油门刹车都会转成扳机阻尼。
⚠️ 震动：还没有适配完，目前仅为实验性。只在 USB 连接下可用，手感还没标定，默认是关闭的；蓝牙连接不提供震动。
（所以想要震动的话请接 USB，并且自己去「手柄」页把开关打开；蓝牙下没有震动不是 bug）

支持的手柄：DualSense / DualSense Edge。
DualShock 4 只做了识别，功能不保证。

===== 项目地址（开源，GPL-3.0）=====
https://github.com/SWTiCC/XY-CtoPS5
发行版是单文件安装程序，装完就是一个桌面程序。

===== 几个注意点 =====
· 只建议用在单人单机游戏上
· 一台 PS5 同一时间只能有一条 Remote Play 连接
· 画面质量取决于你的采集卡，输入走 Remote Play，所以手感主要是「画面延迟 vs 输入延迟」两段
· 映射页内置了一份 gta6 预设，选中就能直接用；推荐设置那两张图是游戏内的灵敏度，不是程序的设置
```
