# 0.3.0 更新说明

## 新增

- **手柄玩法页**：DualSense 连接状态、电量、充电、蓝牙/USB 显示；USB 或蓝牙连接提示
- **DualSense 直通**：按键、摇杆、扳机（模拟量）直通主机，支持蓝牙与 USB
- **陀螺仪 → 右摇杆**：激活键可选；水平/垂直灵敏度、死区、平滑、反转；自动校准（稳定 3 秒自动完成并关闭）
- **自适应扳机（主机下发）**：开枪（0x25）、发动（0x21）、开车油门/刹车（wire 0x05 → 0x21 映射）全部实机验证；支援本地测试效果（阻力/开枪/震动/拉弓）与「停止」
- **USB 原生触觉（实验性，默认关闭）**：主机 haptics 音频解码后写入 DualSense 3/4 声道；手感未标定
- **玩法选择**：键鼠玩法 / 手柄玩法，连接成功后只显示对应页签；手柄玩法下唤醒主机、查看电量
- **连接页提示**：登录/密码界面、Remote Play 占用、待机联网等注意事项

## 修复

- 蓝牙输出报告/CRC、DS5 按键位序修正
- 陀螺仪量纲与 roll 方向修正
- 手柄模式下界面消息洪泛导致“未响应”
- 扳机浅压浅出识别不到（残留读数按 0 发送 + 松开强制补发）
- 会话断开后不再刷 “Session is stopped”

## 已知问题

- 震动为实验性功能：USB 下可解码 haptics 音频，但手感未标定，默认关闭
- 蓝牙下不提供震动（仅自适应扳机）
