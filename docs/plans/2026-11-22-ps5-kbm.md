# PS5 键鼠桥（ps5-kbm）实施计划（2026-11-22）

## 1. 边界：做 / 不做

**做**：
- 在 Windows PC 上把键盘鼠标映射成 DualShock 4 输入，经 PS Remote Play 协议发到 PS5。
- 只走输入通道：不接收/不解码视频（画面继续走用户的 GC553G2B 采集卡环出）。
- 一次性配对（PS5 屏幕 8 位 PIN + PSN Account ID），之后复用凭据。
- 全局热键开关捕获；捕获时锁定光标，鼠标位移映射到右摇杆。
- 可配置的鼠标曲线、死区、灵敏度；键盘映射到左摇杆与按钮；内置 GTA6 预设。

**不做**：
- 不实现 Remote Play 协议本身（复用 pyremoteplay / playdirector，GPL-3.0）。
- 不做视频/音频串流与录制（采集卡负责）。
- 不做 DualSense 自适应扳机、触觉反馈（协议层只有 DS4 数字扳机）。
- 不做反检测/绕过反作弊（GTA6 首发仅单机，暂不涉及）。
- 不做 GUI，先做命令行 + JSON 配置。

## 2. 约束与复用

- 平台：Windows 10/11，Python 3.12（项目 `.venv`）。
- 复用：`playdirector`（pair_console / ConsoleController，2026-10 维护版）与 `pyremoteplay`（RPDevice / Controller.stick / Controller.button）。
- 复用：`pynput` 监听键盘与鼠标按键；`ctypes` 调 `GetCursorPos` / `SetCursorPos` 锁光标。
- 兼容层：`vendor/netifaces.py` 用 psutil 实现 netifaces 接口，绕开 Python 3.12 无 wheel 的编译问题。
- 网络：PS5 与 PC 同一局域网，建议有线。

## 3. 架构：模块、依赖方向、公开接口

```
__main__.py（CLI：scan / pair / run）
   ├── config.py      配置模型 + JSON 读写 + 预设合并
   ├── mapping.py     纯逻辑映射引擎（无 IO，可单测）
   ├── input_source.py pynput 监听 + 光标锁定（IO 适配层）
   └── bridge.py      PS5 会话与输入发送（协议适配层）
```

依赖方向：`__main__ → {config, input_source, bridge, mapping}`；`mapping` 不依赖任何 IO；`bridge` 只依赖 pyremoteplay/playdirector；`input_source` 只依赖 pynput/ctypes。

## 4. 契约

- `MapperConfig`：`sensitivity`、`curve`、`deadzone`、`invert_y`、`left_stick_max`、`drive_max_output`。
- `InputMapper`：
  - `on_key(name: str, pressed: bool)`：name 为小写字母或 `space/shift/ctrl/alt/tab/esc/up/down/left/right/f1..f12`。
  - `on_mouse_button(name: str, pressed: bool)`：name 为 `left/right/middle/x1/x2`。
  - `on_mouse_delta(dx: int, dy: int)`：累积位移。
  - `tick() -> TickResult`：返回 `left: (x, y)`、`right: (x, y)`、`events: list[(button, "press"|"release")]`。
- 按钮名统一用 pyremoteplay 的 `FeedbackEvent.Type`：`CROSS/CIRCLE/TRIANGLE/SQUARE/L1/R1/L2/R2/L3/R3/UP/DOWN/LEFT/RIGHT/OPTIONS/SHARE/PS/TOUCHPAD`。
- `Ps5Bridge`：`connect(credentials)`、`set_sticks(left, right)`、`send_button(name, action)`、`close()`。
- 配置 JSON：`ps5`（host、credentials_path）、`hotkey`、`mouse`、`left_stick`、`keyboard_buttons`、`keyboard_sticks`、`mouse_buttons`、`preset`。

## 5. 数据与状态

- 配对结果保存为 `credentials.json`（含 `device_ip`、`host_id`、`profiles`，**含注册密钥，属于敏感文件，不入库**）。
- 运行时状态只存在内存：按键集合、鼠标累积量、按钮上一帧状态。
- 单一事实来源：配置 JSON；预设只是配置的合并来源（预设 < 用户配置）。

## 6. 失败与边界

- 配对失败：PIN 错误/过期 → 提示重新生成 PIN；主机未开启远程游玩 → 明确报错。
- 会话断开：给出重连命令；不自动无限重试（避免刷屏）。
- 鼠标锁定失败（SetCursorPos 被拒）：降级为不锁定模式并告警。
- 热键冲突：F8 可配置。
- 失焦：捕获模式与窗口焦点无关（全局监听），但建议配合采集卡全屏窗口使用。
- 未知按键：忽略并 debug 日志，不抛异常。

## 7. 演进与扩展点

- 预设机制：新增游戏 = 新增 `presets/<game>.json`，不改代码。
- 输入源：`input_source` 可替换为 Raw Input（更低延迟）而不动 `mapping`。
- 传输层：若 pyremoteplay 协议失效，可把 `bridge` 换成 chiaki-ng + vgamepad 实现，接口不变。
- 摇杆曲线：`mapping` 里集中一个函数，未来可加自定义曲线表。

## 9. 验证：命令 / 测试 / 验收标准

- `python -m pytest tests` 全绿（映射逻辑覆盖：死区、曲线、Y 轴反向、摇杆对角归一化、按钮 press/release 差分）。
- `python -m ps5kbm scan` 能发现局域网 PS5（需要用户环境）。
- `python -m ps5kbm pair --host <ip> --account-id <id> --pin <8位>` 保存凭据（需要用户环境）。
- `python -m ps5kbm run` 连接后，PS5 主界面可用方向键/叉键导航（需要用户环境）。
- 无法在本机验证的部分：真实 PS5 会话、PS5 固件兼容性、GTA6 手感。交付时明确标注。

## 10. 熵账本

**新增的债**：
- `vendor/netifaces.py` 是 shim，若 pyremoteplay 升级用到 `gateways()` 需补实现。
- 依赖 GPL-3.0 的 playdirector/pyremoteplay；本项目按 GPL-3.0 兼容分发（自用不受影响）。
- 会话断线不会自动重连，需手动重启（先简单，观察后再加）。

**偿还计划**：
- 若用户实测 pyremoteplay 协议失效，迁移 `bridge` 到 chiaki-ng + vgamepad，`mapping` 复用。
- 收集 GTA6 实机手感后，补第二版预设参数。
