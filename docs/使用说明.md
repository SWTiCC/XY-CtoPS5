# 使用说明与排障

## 一、它到底在做什么

PS5 的 Remote Play 协议允许一个"已配对客户端"向主机发送手柄输入，同时回传视频。
本项目只借用**输入那一半**：

```
PC 键鼠 ──pynput──> 映射引擎 ──pyremoteplay──> PS5（伪装成 DualShock 4）
PS5 ──HDMI──> 采集卡环出 ──> 显示器（画面完全不经过本程序）
```

因为不接收视频，CPU 占用很低（< 5%），画质和延迟完全由采集卡决定。

## 二、完整流程

### 第 1 步：准备 PS5

1. 设置 → 系统 → **远程游玩** → 启用远程游玩
2. 同一页面 → **关联设备** → 会显示一个 8 位 PIN（每次进入都不同，10 分钟内有效）
3. 记下 PS5 的局域网 IP（`run.cmd scan` 也能看到）

### 第 2 步：扫描

```powershell
.\run.cmd scan
```

输出形如：

```
PS5Pro-Yi    192.168.1.38    PS5    C0151BBD7687
```

如果扫描不到：

- PS5 没开机或没启用远程游玩
- PS5 和 PC 不在同一网段（比如 PC 连了 VPN、或用了次级路由）
- Windows 防火墙拦了 UDP 广播（临时关闭防火墙测试）

### 第 3 步：取 PSN Account ID

```powershell
.\run.cmd login
```

按提示在浏览器登录 PSN，登录成功后浏览器会跳转到 `remoteplay.dl.playstation.net/...`（可能显示空白页）。
把地址栏的完整 URL 复制粘贴回命令行，程序会打印 `Account ID`。

如果 Sony 的登录接口超时：
- 先确认浏览器能打开 `https://auth.api.sonyentertainmentnetwork.com/`
- 需要走代理时，在运行 `login` 的命令行里先设置：
  ```powershell
  $env:HTTPS_PROXY = "http://127.0.0.1:7890"
  ```

**备选方式**（不经过本程序）：

- 如果你用过 **chiaki-ng**，它的注册流程会显示 Account ID；
- `pyremoteplay <PS5的IP> --register` 也有交互式注册向导（与本项目共用 `~/.pyremoteplay` 配置）。

### 第 4 步：配对

PS5 上保持"关联设备"页面显示 PIN，然后：

```powershell
.\run.cmd pair --host 192.168.1.38 --account-id <第3步的ID> --pin <8位PIN>
```

成功后会生成 `credentials.json`（含注册密钥，**不要外传、不要提交到 git**）。

配对失败排查：

| 报错 | 原因 |
|---|---|
| `Turn on the console and enable Remote Play` | PS5 没开机 / 远程游玩没启用 / IP 不对 |
| `Pairing failed; generate a fresh console PIN` | PIN 过期或输错，回 PS5 重新进入"关联设备"拿新 PIN |
| `Invalid PSN account ID` | Account ID 格式不对（要十进制或 Base64 的 8 字节） |
| 超时 | 防火墙拦截，或 PS5 和 PC 之间网络不通 |

### 第 5 步：运行

```powershell
.\run.cmd run
```

看到 `已连接到 <IP>，输入通道就绪` 即可。先按 **F8** 开启捕获，然后在 PS5 上试：

- WASD 应该能在主界面移动
- 回车（Esc 映射的 OPTIONS）能返回
- 鼠标移动应该能转视角

**注意**：捕获开启时鼠标会被锁在屏幕中心，这是正常现象；按 F8 关闭后恢复。

## 三、调参详解

配置在项目根目录 `config.json`，改完重新 `run` 生效。

### 鼠标 → 右摇杆

```json
"mouse": {
  "sensitivity": 1.0,   // 2000px/s 鼠标速度 → 摇杆满偏 × sensitivity
  "curve": 1.0,         // 1.0 线性；>1 慢速更精细、高速更冲
  "deadzone": 0.02,     // 小于该值归零，防漂移
  "invert_y": false,
  "smoothing": 0.0      // 0~0.9，越大越平滑越滞后
}
```

推荐调法：

1. 先只调 `sensitivity`：在游戏里转一圈视角，找到"能接受的最快"；
2. 觉得近距离瞄准太粗，把 `curve` 加到 1.3~1.5；
3. 静止时视角慢漂，`deadzone` 加到 0.03~0.05；
4. 最后才考虑 `smoothing`（它会让瞄准变"粘"）。

### 键盘 → 左摇杆

```json
"left_stick": {
  "max_output": 1.0,        // 步行/跑步满推
  "drive_max_output": 0.8   // F9 切到驾驶模式后的上限
}
```

GTA6 驾驶时左摇杆是转向，键盘一按就是满舵容易甩尾；上车后按 **F9** 切驾驶模式，转向会柔和很多。

### 键位

- `keyboard_sticks`：方向键映射（`up`/`down`/`left`/`right` 各一个键名列表）
- `keyboard_buttons`：键盘按键 → 手柄按钮
- `mouse_buttons`：鼠标按钮 → 手柄按钮

键名用 pynput 写法：字母小写（`w`、`e`），特殊键用 `space`、`shift`、`ctrl`、`alt`、`tab`、`esc`、`up`、`down`、`left`、`right`、`f1`~`f12`。
按钮名：`CROSS`（✕）、`CIRCLE`（○）、`SQUARE`（□）、`TRIANGLE`（△）、`L1`、`R1`、`L2`、`R2`、`L3`、`R3`、`UP`、`DOWN`、`LEFT`、`RIGHT`、`OPTIONS`、`SHARE`、`PS`、`TOUCHPAD`。

### GTA6 游戏内设置

- 瞄准模式：**Part（部分辅助）** 或 Full；不要 Free Aim（30fps 下摇杆模拟根本瞄不住）
- 辅助瞄准强度：**4~5**
- 瞄准响应曲线：**线性**
- 视角/瞄准灵敏度：比手柄默认高一些

## 四、典型问题

### Q：启动后一直显示"正在检测局域网里的已配对主机"

检测只读主机身份、不建立会话：在线一般 1~3 秒出结果，主机没开机时最多等 20 秒（超时按"检测出错"处理）。
检测跑在后台线程，不会卡住界面，可以先切到「映射」「运行」页做别的。

想手动重试：快捷页的 **重新检测**，或完整流程页提示条上的 **重新检测**。

### Q：明明 PS5 开着，却提示"没找到已配对主机"

1. 确认 PS5 上「启用远程游玩」是开着的（关机 / 待机会被当成不在线）；
2. PS5 和 PC 是否在同一网段（PC 挂了 VPN 或走次级路由时广播出不去）；
3. Windows 防火墙是否拦了 UDP 广播（临时关掉防火墙验证）；
4. 换了新的 PS5 或换过 PSN 账号？点 **换 ID 连接** 重新走一遍配对。

### Q：连接成功，但游戏里没反应

1. 确认按了 **F8**（捕获开启）
2. 确认 PS5 前台没有别的 Remote Play 会话（PS Portal / 手机 / 另一台 PC 会抢占）
3. 看程序日志是否有 `Controller has no session` / `Session is not ready`
4. 把 `--verbose` 打开再跑一次：`.\run.cmd --verbose run`

### Q：能走能转，但按键错乱

对照上表检查 `config.json` 的三组映射；GTA6 的"互动"是十字键右，不是 ○。

### Q：视角一直转，停不下来

鼠标死区太小或 `smoothing` 太高导致残值。把 `deadzone` 加到 0.03+，`smoothing` 归零。

### Q：视角很卡、拖尾明显

正常现象：GTA6 锁 30fps，每帧 33ms，鼠标信号被 30Hz 采样。可以：
- 提高 `sensitivity`，少做长距离甩动；
- 接受"手柄化"的瞄准节奏，靠辅助瞄准；
- 实在不行，回到手柄。

### Q：想用 4K/120Hz 画面

采集卡环出已经是 4K144 通道，本程序不参与画面，不受影响。

### Q：PS5 固件更新后连不上了

pyremoteplay 的协议实现可能落后于新固件。先更新依赖：

```powershell
.\.venv\Scripts\python.exe -m pip install --upgrade playdirector
```

若仍失败，改用 chiaki-ng + vgamepad 方案（映射层可直接复用，需替换 `bridge.py`）。

### Q：同时开 OBS 录制会卡吗

不会。本程序只占一条输入 UDP 连接，与采集卡/USB 带宽无关。

## 五、图形界面与输入拦截

### 启动

```powershell
.\run-app.cmd
```

界面分三个页签：

| 页签 | 用途 |
|---|---|
| 连接 | 首次：扫描主机、配对（Account ID + PIN）、建立会话；已配对：一键直接连接 |
| 映射 | 表格编辑键位；支持单按钮 / 组合键 / 序列宏；可切换预设并保存 |
| 运行 | 开始/停止捕获、驾驶模式开关、使用提示 |

底部日志区会显示扫描、配对、检测、连接、捕获状态。

### 连接页的两种视图

**完整流程视图**（第一次用）：

1. 填 PS5 IP（也可先点「扫描局域网」，点列表里的主机自动填入）；
2. 填 PSN Account ID 和 PS5 屏幕上的 8 位 PIN；
3. 点「配对」→ 成功后点「连接主机」。

**快捷连接视图**（配对过之后自动出现）：

- 程序启动时自动检测「已配对的那台主机在不在当前局域网」，按主机 ID 匹配——
  PS5 重启后 DHCP 换了 IP 也能扫描找回，并把新 IP 写回 `credentials.json`；
- **在线**：显示主机名 + IP，点 **直接连接** 建立输入通道，**断开** 可用；
- **换主机 / 换 PSN 账号**：点 **换 ID 连接** 回到完整流程；
- **不在线 / 检测出错**：自动回到完整流程视图，顶部提示原因；点 **重新检测** 重试，
  或按下面的流程重新配对；已经配对过时，提示条上的 **用已配对主机** 可以回到快捷视图。

> 「在线」只代表能读到主机状态。真正建立会话仍以连接结果为准：
> 主机被其它 Remote Play 客户端占用时，仍会弹出「主机被占用」提示。

### 动作类型

| 类型 | 配置写法（config.json） | 说明 |
|---|---|---|
| 单按钮 | `"space": "CROSS"` | 按下即按 |
| 组合键 | `"g": {"chord": ["L1", "R1"]}` | 按下时同时按住多个按钮 |
| 序列宏 | `"h": {"sequence": [["UP", 0.05], ["CROSS", 0.05]]}` | 依次按下，第二项是保持秒数；按下一次整套执行一次 |

序列执行中再按另一个序列会打断旧的并释放其按钮。键盘自动重复会被过滤，不会重复触发序列。

### 输入拦截怎么工作

捕获开启后：

- 键盘事件由 pynput 的 `suppress` 吞掉，不再传给 Windows；
- 鼠标移动/点击同样被吞，系统光标不再移动；
- 位移改由 **Raw Input**（设备原始报文）读取，所以不需要把光标锁在中心；
- F8/F9 仍会被程序收到（热键不会被"吞掉失灵"），只是不会打到 PC。

先验证 Raw Input：

```powershell
.\run.cmd test-input
```

按提示移动鼠标，能打印出 `dx/dy` 累计值才说明拦截模式可用。
如果不可用（安全软件拦截、远程桌面等），程序会**降级为不拦截鼠标 + 光标轮询模式**：
键盘仍然拦截，鼠标事件会落到 PC 上，但映射继续可用。

### 界面上的注意事项

- 捕获开启时鼠标被接管，此时用 **F8** 关闭（界面按钮点不到是正常的）。
- 编辑映射后需要重新开始捕获才生效（程序会提示）。
- 关闭窗口会自动停止捕获、释放会话，不会把 PS5 留在"卡键"状态。

## 六、安全与合规

- `credentials.json` 含主机的注册密钥，等同于"免 PIN 登录凭据"，请勿分享。
- 模拟手柄输入属于第三方输入设备，是否违反游戏条款由发行商决定。
  **GTA6 目前只有单人战役，无在线反作弊**；GTA6 Online 上线后请自行评估。
- 不要在联机竞技游戏里配合宏/连发脚本使用，那属于作弊。
